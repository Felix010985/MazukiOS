# MazukiOS

MazukiOS — это независимая операционная система, разрабатываемая с нуля на базе оригинального ядра **Masix**. Проект стремится к созданию чистого UNIX-подобного окружения с перспективой бинарной совместимости с Linux (на уровне системных вызовов).

# Архитектурные возможности

Проект представляет собой монорепозиторий, который четко разделен на низкоуровневое ядро **Masix** (sys/) и операционную систему **MazukiOS** с пользовательским пространством. (world/)

## ⚙️ Ядро Masix
* **Ядро с нуля**: Полностью независимое монолитное/мультисерверное ядро для архитектуры x86 (i686).
* **Слои абстракции драйверов**: Аппаратные драйверы изолированы в `sys/kernel/drivers/`, а их публичные интерфейсы вынесены в `<drivers/...h>`.
* **Файловая подсистема**: Изолированная VFS, ramfs, procfs и devtmpfs находятся в `sys/kernel/fs/` с внутренними заголовками в `sys/kernel/fs/include/`.
* **Сетевой стек (Ранний этап)**: 
  - Сетевой драйвер Realtek RTL8139 (PCI) с поддержкой опроса (polling) RX/TX и реализацией ARP для статического IP `10.0.2.15`.
  - Локальная сеть (Loopback): базовый стек `AF_INET` + `SOCK_DGRAM` (UDP) для адреса `127.0.0.1`.
* **Интерфейс системных вызовов**: Номера Linux-подобных сисколлов и структура `struct syscall_regs` стандартизированы в `sys/kernel/include/syscall.h`.
### 🔄 Подсистемы VFS, IPC и Сети ядра
* **Файловые системы Linux**: Файловые системы `/proc` и `/dev` (devtmpfs), а также механизмы `pipe` и `pipe2` работают через стандартные Linux-совместимые системные вызовы.
* **Unix-сокеты**: Полноценная поддержка локального IPC через `AF_UNIX` + `SOCK_STREAM`. Реализована поддержка Linux i386 `socketcall` (`bind`, `listen`, `connect`, `accept`, `send`, `recv`).
* **Сетевые интерфейсы**: Поддержка функций `bind`, `connect`, `sendto` и `recvfrom` для UDP трафика.

## 🌐 Операционная система MazukiOS (Userland / Пространство пользователя)
* **Изолированное окружение (world)**: (Полноценная) пользовательская среда, работающая в Ring 3.
* **Интерфейс и оболочка**: Базовый TTY-терминал и минималистичный Shell, написанные на C.
* **Стандартная библиотека**: Интегрированная библиотека `musl libc` для обеспечения совместимости с современным ПО.

## 🛠️ Сборка и запуск

### Требования к окружению
Чтобы собрать окружение достаточно просто запустить скомпилированный файл configure.c (см. шаг 2)

### Быстрый старт
Вся сборка полностью автоматизирована через `Makefile`.

1. **Клонирование и подготовка:**
   ```bash
   git clone https://github.com/Felix010985/MazukiOS.git
   cd MazukiOS
   ```

2. **Автоматическая настройка окружения:**
   ```bash
   (ваш компилятор) tools/configure.c -o conf
   ./conf
   ```

3. **Сборка проекта и создание ISO-образа:**
   Команда автоматически скомпилирует ядро (`sys/`), компоненты системы (`world/`), соберет правильную структуру GRUB и упакует ISO:
   ```bash
   make iso
   ```

4. **Запуск в QEMU:**
   ```bash
   make run
   ```

## 📑 Структура репозитория
- `sys/` — Исходный код ядра Masix (управление памятью, прерывания, сисколлы, драйверы).
- `world/` — Собственный юзерленд **MazukiOS** (командная оболочка `sbsh` и системные утилиты).
- `include/` — Общие заголовочные файлы системы.
- `linker.ld` — Скрипт линкера для сборки ядра под архитектуру x86 (Multiboot2).

### Про комментариями
Решение о оснащении кода комментариями не было принято спонтанно — код ядра **Masix** уже просто слишком огромен, чтобы полагаться исключительно на простые комментарии в 
виде "// вот тут делается вот это", оснащение комментариями было сделано в первую очередь для удобства разработчиков которые могут захотеть помочь такому проекту достичь целей. 
Многим не нравятся комментарии, многие считают их слишком "влажными" для серьезного кода, у многих они вообще ассоциируются с низкосортным машинно-сгенерированным кодом, и я, и 
другие что следят за этим проектом понимают это, но это вынужденная мера для поддержания внутренней чистоты кода, даже если за это придется заплатить килобайтами места в репозитории.
Спасибо за понимание!
